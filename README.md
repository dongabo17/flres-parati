# Flores amarillas para ti 💛

Una pequeña página web animada, tierna y divertida para compartir un detalle especial.

## Ver la página

Activa GitHub Pages en **Settings → Pages**, seleccionando la rama `main` y la carpeta `/ (root)`. Después podrás compartir el enlace público que GitHub genere.

La página es completamente estática y funciona sin instalación ni dependencias.
